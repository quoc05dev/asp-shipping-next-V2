# PHASE 12 LEGACY INNER PAGE AUDIT

## 1. Executive Summary
This document provides a comprehensive inventory and migration map for existing inner pages found in the `legacy-approved` directory. The goal is to migrate these pages with near-pixel-fidelity into the Next.js application while stripping away legacy dependencies such as WordPress runtime scripts, jQuery, and extraneous plugins.

## 10. Shared Component Opportunities
- **Inner Page Hero:** A standard banner header with title and breadcrumbs.
- **Introductory Text Block:** Wide, legible text container for lead paragraphs.
- **Two-Column Text/Image:** Alternating editorial layout.
- **Statistics Block:** Grid layout for company metrics.
- **Call To Action (CTA) Block:** Standardized bottom-of-page navigation block.
- **Leadership Cards:** Grid of profiles.

## 11. WordPress/Runtime Dependencies to Remove
- jQuery (`jquery.min.js`, etc.)
- Contact Form 7 (`wpcf7` runtime)
- CleanTalk anti-spam scripts
- WordPress emoji/i18n scripts
- WordPress Rest API calls
- Inline `<style id="wp-custom-css">` that are redundant

## 12. Recommended Migration Order
1. **Phase 12B:** About Us main page
2. **Phase 12C:** About Us - History
3. **Phase 12D:** About Us - Leadership
4. **Phase 12E:** About Us - Vision / Mission / Values
5. **Phase 12F:** About Us - Trades
6. **Phase 12G:** Sustainability and child pages

## 13. Risks
- **Forms:** The Contact Us page relies on Contact Form 7. A custom API route and React form state will be required.
- **Dynamic Content:** Media/news lists were likely generated by PHP. We will need a static MDX or JSON data approach for news articles.
- **Missing Assets:** Ensure all background and inline image paths are correctly mapped to `/public` and Next/Image.

## 14. Phase 12B Recommendation
Proceed with migrating the **About Us main page** (`/about-us`) to establish the shared Inner Page Hero and general editorial layout patterns, which will streamline the rest of the family.
